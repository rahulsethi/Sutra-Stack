Three shapes — the user chooses one

Each shape is a complete product. (a) needs no account, no key and no network. Each later shape adds a surface without changing the gate: the ceiling differs, the enforcement does not.

(a) is a real product

  • With no key at all, retrieval, tiering, linking, the graph and cited answers work.
  • A first run that only announces its own limitations is not a product — so the deterministic answer is the floor, not the fallback.

(b) is the default

  • The harness brings the model, keys, chat, channels and scheduling.
  • Sutra is the governed substrate they plug into — not a competitor to any of it.
  • sutra doctor --harness X asserts 14 tools AND a ceiling by speaking the protocol.

(c) must be removable

  • Release gate 5: uninstalling the daemon and dashboard breaks nothing in (a) or (b).
  • Enforced by them being separate packages that nothing else imports.
