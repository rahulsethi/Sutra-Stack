Sutra — Diagrams

Hand-laid inline SVG in self-contained dark HTML. No Mermaid and no client-side layout step, so a diagram cannot degrade to a white page or to haphazard routing. Every one renders offline; drag to pan, wheel to zoom, hover a box to isolate it.

The Gate — four independent enforcement points

Every read path in the product passes all four. They are deliberately redundant: each one has failed independently in the system Sutra was extracted from, and the other three held. The ceiling is read from the environment at server startup and is never accepted as a tool argument — a model can ask for anything, and cannot change what it is allowed to see.

The pipeline — ingest → compile → graph → index

Four stages, each a script that runs alone, orchestrated by daily.ps1. Every stage reports one of five distinct outcomes and holds the resource locks it writes. Degradation is allowed; silent degradation is not.

Architecture — and the licence boundary

Everything outside ee/ is Apache-2.0. ee/ is commercial. The dependency arrow points one way — Core never imports from ee/ — and CI proves it on every commit by deleting the subtree and running the full suite.

Three shapes — the user chooses one

Each shape is a complete product. (a) needs no account, no key and no network. Each later shape adds a surface without changing the gate: the ceiling differs, the enforcement does not.

The MCP surface — 13 reads, 1 write

Hand-rolled JSON-RPC 2.0 over stdio, zero external dependencies, so a user auditing the thing that decides what their AI can see reads ~700 lines and nothing else. No tool accepts a ceiling, tier, scope, override or passphrase — a test walks every published schema on every build.

What this build refused to inherit

Sutra is an extraction from a live system, so by default it inherits every defect that system had — including the ones that had been shipping unnoticed for years. Each is closed by a named test that fails against a planted instance, because a guardrail test that has never been seen to fail is not evidence of anything.
Regenerate: node scripts/diagrams.mjs. The layouts are hand-placed coordinates — the part that needs judgement — while the shell, palette and legend are generated, so the set cannot drift apart visually. A structural change is not done until its diagram follows.

Offline: the diagrams render with no network. Only PNG/PDF export needs a CDN, and the buttons say so rather than failing mysteriously.
