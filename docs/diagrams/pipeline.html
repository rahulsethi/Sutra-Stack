The pipeline — ingest → compile → graph → index

Four stages, each a script that runs alone, orchestrated by daily.ps1. Every stage reports one of five distinct outcomes and holds the resource locks it writes. Degradation is allowed; silent degradation is not.

Why five outcomes

  • Upstream, an LLM failure was caught, counted as a skip, labelled pending/no-extract, and exited 0.
  • That one sentence let a 26-day outage look like a quiet week.
  • did_work is three-valued — true/false/null = not measurable — so the fix cannot misfire the other way and cry “did nothing” without proof.

No input clip, ever

  • One line truncated every source to 6,000 chars. It produced 424 pages that were fluent, correctly formatted, and wrong in specifics.
  • Page length was flat across two orders of magnitude of source size, so nothing looked anomalous.
  • source_chars_seen and _total now make truncation a fact on the artifact.

Why the locks are ranked

  • Three jobs once wrote one artifact with no lock. IgnoreNew guards a task against itself, never against another.
  • Ascending-rank acquisition makes circular wait impossible by construction.
  • A global lock was rejected: it would freeze the graph for every long run, and that graph has already been lost once.
