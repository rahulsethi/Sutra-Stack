What this build refused to inherit

Sutra is an extraction from a live system, so by default it inherits every defect that system had — including the ones that had been shipping unnoticed for years. Each is closed by a named test that fails against a planted instance, because a guardrail test that has never been seen to fail is not evidence of anything.

It happened again during this build

  • The positive-coverage test caught three detection rules whose fixtures were one character short of their own patterns.
  • Dead rules — and a rule that matches nothing looks exactly like a rule protecting a clean corpus.
  • Found before the first commit rather than after a year of shipping.

Two more, found by running it

  • The first cited answer on a fresh install quoted a template file full of {{title}} placeholders as a source.
  • The shipped note templates defaulted to public — a template that mints public notes contradicts the vault's own rule.
  • Neither would have been found by reading the code.

And one inside a check

  • check-core-alone carried stale build state into its staged copy, so tsc emitted nothing and exited 0.
  • It reported a passing build with no compiled output — D18's exact shape, inside the script written to catch such things.
  • It now asserts the builder produced output rather than inferring it.
