# Note templates

These are starting points for new notes. Copy one, fill it in, delete what you
do not need. Nothing in Sutra requires you to use them — a note is any markdown
file with a frontmatter block.

## They all default to `sensitivity: private`

Deliberately, and it is worth understanding why rather than changing it on the
first day.

An unlabelled or default-labelled note is not one you decided was safe to share
— it is one nobody has looked at yet. If templates defaulted to `public`, then
every note you created from one and forgot to review would be visible to a
cloud model. The cost of the private default is that you promote notes
deliberately; the cost of a public default is paid once, invisibly, and cannot
be taken back.

Change a note to `public` per note, when you have decided it.

## Licensing

The templates in this directory are part of Sutra Core and are licensed under
Apache-2.0, declared here for the whole directory.

They deliberately carry **no per-file SPDX header**: a template's bytes become
*your* note. A licence line inside `daily-log.md` would end up at the top of
every daily note you ever write, asserting a copyright claim over your own
writing. Notes you create from these templates are yours, entirely, under no
licence from us.
